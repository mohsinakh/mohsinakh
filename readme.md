### whoami

I'm Mohsin — an AI/ML engineer with **1+ year of production experience at ICMR HQ** (Indian Council of Medical Research, New Delhi), where my models run in real healthcare-research pipelines: a **YOLO anemia-detection system at 92% accuracy** serving a live clinical inference API, multimodal deep learning (Wav2Vec2 + NLP, ~87%), and REST APIs handling **1,000+ requests/day**.

I learn by building things from the inside out. I'm not satisfied knowing *that* a transformer works; I want to know what happens between a token going in and a prediction coming out. So I rebuild the interesting parts myself — the model, the retrieval stack, the data structure — instead of importing them and hoping.

**Focus: LLM systems (RAG, agents, fine-tuning), computer vision, and the backend APIs that put them in front of real users.**

### Things I've built

**[RAG Research Paper Assistant](https://github.com/mohsinakh/rag-research-paper-assistant)** — a hybrid retrieval-augmented generation service over academic papers: **FAISS dense vectors + BM25 keyword search fused with Reciprocal Rank Fusion**, multi-format ingestion (PDF/DOCX/HTML/+6 more), and citation-forcing LLM synthesis (Claude API → local Ollama fallback). Hybrid retrieval cut hallucinations **40%** on internal benchmarks. Runs fully offline; shipped as a FastAPI service.

**[GPT-2, reimplemented in PyTorch](https://github.com/mohsinakh/gpt2)** — the full architecture by hand (attention, transformer blocks, embeddings, the data pipeline), then loaded with OpenAI's real weights and fine-tuned for spam classification and instruction following. The point wasn't a chatbot — it was understanding every tensor.

**[SentimentSense](https://github.com/mohsinakh/SentimentSenseApiMain)** — led a 4-engineer team building a real-time multimodal sentiment engine that reads text, images, video, and live webcam feeds (CNN + Transformers, ~90% accuracy), served over FastAPI with WebSocket streaming and a [React front-end](https://github.com/mohsinakh/sentimentSenseFrontend). → [live demo](https://sentiment-sense.netlify.app)

**[AI Test Failure Explainer](https://github.com/mohsinakh/ai-test-failure-explainer)** — a Playwright + pytest regression suite with a local Llama 3.1 model wired into the test hooks, so a failed test comes back with a plain-English explanation of *why*. Zero API keys, runs entirely on your laptop.

**[A text editor, from the data structures up](https://github.com/mohsinakh/text-editor)** — a terminal editor in pure Python that stores text in a persistent rope tree: O(log n) edits and undo/redo that costs almost nothing, the same trick VS Code uses under the hood.
