### whoami

I'm Mohsin — an AI/ML engineer who learns by building things from the inside out. I'm not satisfied knowing *that* a transformer works; I want to know what happens between a token going in and a prediction coming out. So I tend to rebuild the interesting parts myself — the model, the data structure, the failure loop — instead of importing them and hoping.

Right now that means **AI systems, NLP, computer vision, and the backend APIs that put them in front of real users.**

---

### Things I've built from scratch

**[GPT-2, reimplemented in PyTorch](https://github.com/mohsinakh/gpt2)** — the full architecture by hand (attention, transformer blocks, embeddings, the data pipeline), then loaded with OpenAI's real weights and fine-tuned for spam classification and instruction following. The point wasn't a chatbot — it was understanding every tensor.

**[SentimentSense](https://github.com/mohsinakh/SentimentSenseApiMain)** — a real-time multimodal sentiment engine that reads text, images, video, and live webcam feeds (CNN + Transformers), served over FastAPI with WebSocket streaming and a [React front-end](https://github.com/mohsinakh/sentimentSenseFrontend). → [live demo](https://sentiment-sense.netlify.app)

**[AI Test Failure Explainer](https://github.com/mohsinakh/ai-test-failure-explainer)** — a Playwright + pytest regression suite with a local Llama 3.1 model wired into the test hooks, so a failed test comes back with a plain-English explanation of *why*. Zero API keys, runs entirely on your laptop.

**[A text editor, from the data structures up](https://github.com/mohsinakh/text-editor)** — a terminal editor in pure Python that stores text in a persistent rope tree: O(log n) edits and undo/redo that costs almost nothing, the same trick VS Code uses under the hood.
